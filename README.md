# Mood-Based Color Palettes

A Chrome/Edge browser extension for exploring ten mood-based palettes and copying HEX color values.

## Install locally

1. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
2. Turn on **Developer mode**.
3. Choose **Load unpacked** and select this repository folder.
4. Pin **Mood-Based Color Palettes** to the toolbar to open the popup.

The extension uses local files and requests clipboard-write access for the swatch copy action. It does not access websites or send data elsewhere.
